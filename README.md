# Note DNA

HTML, CSS, JavaScript로 만든 노트·개인화·학습 UI 프로토타입입니다.

- 배포: https://siajin.github.io/gyeol-notes/
- 로컬 실행: `python -m http.server 4174 --directory notion-ui`

## 화면 구성

왼쪽은 노트 목록과 검색, 가운데는 본문, 오른쪽은 DNA 설정입니다. 과목 하나당 노트 하나를 사용합니다. 오른쪽의 상세 설정을 열면 패널이 넓어지며, 학습하기를 누르면 왼쪽 목록을 유지한 채 학습 화면으로 이동합니다. 작은 화면에서는 각 패널을 따로 열 수 있습니다.

- **사용자 DNA:** 문체와 표·목록, 단계별 번호, 강조 표시와 빈도를 세 그룹으로 표시합니다.
- **노트 DNA:** 내용(단락 구분·정리 순서·분량·설명 수준), 수식과 용어, 내용 보충(예시·자료 우선순위·외부 보충·시각자료)입니다.
- **템플릿:** 개념 이해·심화 학습·시험 대비와 사용자가 저장한 템플릿을 오른쪽에서 선택합니다. 기본 템플릿은 노트 설정을 일괄 적용하고, 사용자 템플릿은 저장한 사용자 DNA도 적용합니다.
- **문제 생성 설정:** 범위를 먼저 선택하고 챕터별·융합, 유형, 개수와 난이도를 고릅니다. 별도 학습 DNA 화면은 없습니다.

번호는 1~4단계마다 설정합니다. 예시 종류를 모두 해제하면 예시 없이 정리하며 개수 입력은 숨깁니다. 수식 여부는 수식과 용어 그룹의 첫 항목입니다. 노트 DNA의 접기 그룹은 한 번에 하나만 열립니다. 설정은 자동 저장되며, 본문을 자동으로 다시 쓰지는 않습니다.

## 명세서를 반영한 동작

- 새 노트 생성, 같은 과목에 자료 추가, 자료별 역할 지정, 원본 보관·열기
- 텍스트·Markdown 가져오기, 수업 필기 첨부와 텍스트 반영
- 블록 편집·이동·메모·선택 강조, 수정 비교·적용과 실행 취소
- 블록별 요청문 및 전체 수정 방향 저장, 원본 자료 연결
- 사용자 템플릿·프롬프트 저장·검색·편집·적용·공유 파일 가져오기
- 노트 제목과 본문을 이용한 객관식·단답형·OX·서술형 연습 문제
- 답안 저장·제출, 객관식/OX/단답형 채점, 서술형 자기 평가, 오답 표시·필터·재풀이, 관련 본문으로 이동
- Markdown·HTML·공유용 JSON·인쇄/PDF 내보내기, 출처·교수 설명·메모 포함 여부 선택
- 템플릿 공유 목록·좋아요·가져오기·정렬의 로컬 체험
- 시각자료 종류별 편집 가능한 구성 초안 삽입
- 편집 습관 추천·적용·무시·기록 초기화, DNA 기본값 복원

## 실제 연결 범위

이 버전은 서버 없는 프런트엔드입니다. AI 서비스, PDF/PPT 본문 분석·OCR, 외부 학술자료 검색, 온라인 커뮤니티, 계정·기기 동기화는 연결되지 않았으며 관련 화면에 이를 표시합니다. PDF와 이미지 등은 원본을 보관하고, 텍스트 파일은 실제 본문으로 가져옵니다. 생성한 문제는 본문을 추출해 구성한 연습용이며, 심화 AI 출제나 의미 기반 서술형 자동 채점은 아닙니다. 시각자료는 제목을 배치한 편집용 초안입니다. 커뮤니티 등록은 외부 공개 없이 이 기기에 저장되며, 실제 전달은 공유 파일로 가능합니다.

## 데이터 유지

`gyeol.workspace.v1` localStorage와 `gyeol-files` IndexedDB를 유지합니다. 기존 설정 버전 4~6의 마이그레이션을 보존했습니다. 작업 공간 버전 1에서 같은 과목의 노트들을 합치되 모든 블록·필기·자료·문제 세트를 유지하고, 원본 노트 배열을 `beforeWorkspaceNotes`에 보관합니다. 이후 재실행 시 다시 합치지 않습니다. 내부 `personalDNA`, `subjectDNA`, `learningDNA` 키는 호환성을 위해 유지합니다.

노트 목록에서 삭제한 자료와 문제 세트는 같은 세션의 실행 취소로 복구할 수 있습니다. 공유 파일은 원본 첨부 파일을 포함하지 않습니다. 다른 기기로 이동하려면 노트·템플릿 공유 파일과 필요한 원본을 따로 보관하세요.

## 파일

- `index.html`: 진입점
- `workspace.js`, `workspace.css`: 세 영역 화면, 템플릿·생성·공유·학습 흐름
- `app.js`: 기존 편집기·원본 보기·블록 조작
- `settings.js`: 설정, 마이그레이션, 자동 저장, 미리보기
- `study-notes.js`: 필기 첨부·반영
- `note-content.js`: 예시 노트 본문
- `styles.css`, `theme.css`: 공통 컴포넌트
- `icon.svg`: 앱 아이콘
