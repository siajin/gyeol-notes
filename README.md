# Note DNA

HTML, CSS, JavaScript로 만든 문서 중심 노트 UI 프로토타입입니다.

- 배포: https://siajin.github.io/gyeol-notes/
- 로컬 실행: `python -m http.server 4174 --directory notion-ui`

## 설정 구조

**기본 DNA**는 처음 방문할 때 5가지(정리 기준, 표와 목록, 강조 방식, 문체, 기본 설명 수준)만 먼저 보여줍니다. 제목 구조, 번호 표기, 예시 개수는 추천값을 사용하며 세부 설정에서 바꿀 수 있습니다. 모든 과목이 이 값을 상속합니다.

**과목별 DNA**는 자료 반영 방식, 수식 설명 수준, 시험 관련 강조, 외부 자료 보강을 먼저 보여줍니다. 직접 조정할 때만 강의자료·교재·개인 필기·교수 설명·외부 학술자료의 비중이 나타납니다. 용어, 시각자료, 문제 생성과 해설은 추가 학습 설정에 있습니다. 수식 없는 과목에서는 수식 항목이 숨겨집니다. 기본 DNA는 필요한 항목만 과목별로 덮어쓸 수 있고, 기본값으로 되돌릴 수도 있습니다.

**이번 노트 설정**은 학습 모드, 학습 범위, 노트 분량 3개로 시작합니다. 자료 선택은 자료가 여러 개일 때, 문제 개수·난이도는 문제를 생성할 때만 나타납니다. 세부 범위, 자유 요청문, 전체 난이도 변경은 해당 노트에만 저장됩니다. 새 노트는 새로운 기본값으로 시작하므로 시험 범위와 요청문이 다음 노트로 넘어가지 않습니다.

개념 이해 / 심화 학습 / 시험 대비 / A+ 종합 노트 모드는 각각 권장 설정을 조합합니다. 일회성 난이도와 자료 제한이 모드 설정보다 우선합니다. 수식·시각자료 미사용은 모드를 바꿔도 유지됩니다. 모든 컨트롤은 자동 저장되며 미리보기에 반영됩니다.

노트 생성 화면에서 새 과목을 선택하면 새 과목 DNA도 함께 설정할 수 있습니다. 첫 방문 설정은 계정 가입 없이 이 브라우저에서 제공됩니다.

## 기존 기능

예시 노트 5개, 핵심 요약, 접는 계산 예제·복습 질문, 직접 편집, 블록 이동, 실행 취소, 검색, 즐겨찾기, 시험 보기, Markdown·HTML·인쇄 내보내기를 지원합니다.

수업 필기는 TXT·Markdown을 읽거나 텍스트를 붙여넣어 정리에 반영합니다. 개인 필기 반영도·중요도·강조 구절 우선 설정을 적용합니다. 특정 자료 선택과 새로 추가한 자료만 반영하는 옵션도 이 흐름에 연결됩니다. 직접 수정한 필기 정리 블록은 다시 반영할 때 보존합니다.

편집 습관 추천은 최근 같은 과목의 최대 5개 노트에서 긴 설명의 감소율을 계산합니다. 노트가 3개 이상이고 평균 20% 이상 줄었을 때 이번 노트 분량을 줄이도록 제안합니다. 적용·무시가 가능하며, 분량 추천이 기본 설명의 전문 수준을 변경하지 않습니다.

## 저장과 마이그레이션

노트와 설정은 localStorage, 원본 파일은 IndexedDB에 저장합니다. 기존 저장 키를 유지해 작성한 내용과 파일을 보존합니다. 이전 과목별 설명 수준과 서식 차이는 명시적 과목별 기본 DNA 예외로 옮깁니다. 예전 자유 요청은 기존 노트에만 옮기고 새 노트에는 복사하지 않습니다.

`personalDNA`는 기본 DNA, `subjectDNA`는 과목 설정, `personalOverrides`는 과목별 기본 DNA 예외, 각 노트의 `runSettings`는 일회성 선택입니다. DNA JSON 내보내기는 이 구조를 포함합니다.

## 제공 범위

설정 저장·상속·조건부 표시·권장 모드·미리보기·텍스트 필기 반영이 동작하는 프런트엔드 프로토타입입니다. 실제 AI 호출, OCR, 자동 문제·시각자료·복습 테이프 생성, 학술자료 검색, 로그인·계정 동기화는 연결되지 않았습니다. 기존 본문을 설정 변경만으로 다시 쓰지 않습니다. PDF·이미지는 원본 보관 후 텍스트를 보완해 반영할 수 있습니다.

## 파일

- `index.html`: 진입점
- `styles.css`, `theme.css`: 기본 레이아웃, 흰 배경, 설정 화면과 반응형 스타일
- `app.js`: 편집기, 탐색, 가져오기, 내보내기
- `note-content.js`: 확장된 예시 노트 및 기존 샘플 보완
- `study-notes.js`: 필기 첨부·반영, 편집 습관 추천
- `settings.js`: 설정 스키마, 상속, 일회성 옵션, 조건부 표시, 모드, 미리보기
- `icon.svg`: 아이콘

## 확인

JavaScript 구문, 정적 자산 참조, 비브라우저 DOM 환경에서 설정 명세 19개, 필기 첨부 12개, 편집기 11개 점검을 통과했습니다. 실제 브라우저 시각·드래그·인쇄 및 IndexedDB 테스트는 별도로 진행하지 않았습니다.
