# Note DNA

HTML, CSS, JavaScript로 만든 문서 중심 노트 UI 프로토타입입니다.

- 배포: https://siajin.github.io/gyeol-notes/
- 로컬 실행: `python -m http.server 4174 --directory notion-ui`

## 개인화 설정

모든 선택 항목은 같은 버튼형이며 제목·선택지·설명 순서로 표시합니다. 관련 항목을 접기 영역으로 묶고, 같은 화면에서는 하나를 열면 나머지를 접습니다. 기본 영역은 처음에 열려 있습니다.

### 기본 DNA

- **기본:** 단락 구분 정도, 문체
- **번호·배치·강조:** 1~4단계 번호, 표와 목록, 강조 표시, 강조 빈도

번호는 단계마다 `1.`, `1)`, `(1)`, `①`, `a.`, `가.`, 글머리표, 없음 중에서 선택합니다. 미리보기에도 단계별 기호를 반영합니다. 단락 구분 정도에 따라 미리보기의 세부 단계가 달라지며 저장한 번호는 유지합니다.

### 과목별 DNA

- **기본:** 학습 모드 일괄 적용, 정리 순서, 노트 분량
- **수식과 용어:** 수식이 있는 과목인지 먼저 선택하고 수식·용어 설명 수준 설정
- **내용 보충:** 예시 종류·개수, 자료 밖의 설명 보충, 강의자료·교재·필기·교수 설명 반영도, 시각자료

필기의 중요도와 강조 구절 우선 반영은 설정 화면에서 제외했습니다. 기존 노트와 저장 데이터는 보존합니다.

예시는 비유·실생활 사례·단계별 풀이·응용을 복수 선택합니다. 모두 해제하면 예시 없이 정리하고 개수 입력을 숨깁니다. 선호 개수는 보존하지만 실제 적용 설정의 개수는 0이며, 종류를 다시 선택하면 개수 입력이 나타납니다. 0개 상태에서 종류를 선택하면 1개로 시작합니다.

### 학습 DNA

**기본** 묶음의 첫 항목은 학습·시험 범위입니다. 이어서 챕터별·챕터 융합, 문제 유형, 문제 개수, 난이도를 설정합니다. 유형은 객관식·단답형·서술형·OX를 복수 선택합니다.

모든 설정은 자동 저장하며 새 과목 생성 화면에도 같은 구성과 동작을 적용합니다. 학습 모드 일괄 적용은 기본 DNA와 학습 DNA를 바꾸지 않습니다.

### 참고한 UI

- [Notion 페이지 서식](https://www.notion.com/help/customize-and-style-your-content): 글꼴·크기 등 관련 서식 설정을 한곳에 모으는 방식을 참고했습니다.
- [Google Docs 목록 설정](https://support.google.com/docs/answer/3300615?hl=en-GB): 번호·글머리표의 모양을 직접 선택하는 방식을 참고해 단계별 기호 선택에 적용했습니다.
- [IBM Carbon 아코디언](https://carbondesignsystem.com/components/accordion/usage/): 관련 정보를 제목 아래 접어두는 구성을 참고했습니다. 한 번에 하나만 펼치는 동작은 사용자 요청에 따라 적용했습니다.

## 기존 기능

예시 노트 5개, 핵심 요약, 접는 계산 예제·복습 질문, 직접 편집, 블록 이동, 실행 취소, 검색, 즐겨찾기, 시험 보기, Markdown·HTML·인쇄 내보내기를 지원합니다.

수업 필기는 TXT·Markdown을 읽거나 텍스트를 붙여넣어 정리에 반영합니다. 개인 필기 반영도를 적용합니다. 특정 자료 선택과 새로 추가한 자료만 반영하는 옵션은 필기 첨부 관리에서 조절합니다. 직접 수정한 필기 정리 블록은 다시 반영할 때 보존합니다.

편집 습관 추천은 같은 과목의 긴 설명을 수정한 노트가 3개 이상이고, 최근 최대 5개의 평균 감소율이 20% 이상일 때 과목별 노트 분량을 줄이도록 제안합니다. 적용·무시가 가능하며 기본 DNA나 학습 DNA는 변경하지 않습니다.

## 저장과 마이그레이션

노트와 설정은 localStorage, 원본 파일은 IndexedDB에 저장합니다. 기존 저장 키를 유지합니다. 버전 4에서는 기본 DNA의 정리 기준·예시 선호도를 과목별 DNA로, 이전 문제 설정과 최근 노트의 시험 범위를 과목별 학습 DNA로 옮깁니다. 기존 과목도 새 모드의 설명·외부 보강 정책으로 한 번 맞춥니다. 이후 직접 바꾼 값은 유지합니다. 이전 설정 스냅샷을 `previousDNA`에 보관하고, 노트 본문·메모·첨부 원본·기존 일회성 데이터는 지우지 않습니다.

- `personalDNA`: 공통 표현 방식
- `subjectDNA`: 과목별 정리 순서와 내용 설정
- `learningDNA`: 과목별 문제·시험 준비 설정

버전 5에서는 이전 예시 설정을 종류 배열(`exampleTypes`)과 개념당 개수(`exampleCount`)로 옮깁니다. 과목별로 별도 저장하며, 기존의 다른 설정이나 노트는 다시 초기화하지 않습니다.

버전 6에서는 이전 번호 프리셋을 1~4단계 개별 설정으로 옮깁니다. 기존 문체·과목별 설정·노트는 유지합니다. 빈 예시 종류 배열도 저장과 재시작 후 그대로 유지합니다.

DNA JSON 내보내기는 이 세 범주와 단계별 번호, 예시 종류·개수를 포함합니다.

## 제공 범위

설정 저장·미리보기·모드 전환·텍스트 필기 반영이 동작하는 프런트엔드 프로토타입입니다. 실제 AI 호출, OCR, 자동 문제·시각자료 생성, 학술자료 검색, 로그인·동기화는 연결되지 않았습니다. 기존 본문을 설정 변경만으로 다시 쓰지 않습니다. PDF·이미지는 원본 보관 후 텍스트를 보완해 반영할 수 있습니다.

## 파일

- `index.html`: 진입점
- `styles.css`, `theme.css`: 기본 레이아웃, 흰 배경, 설정 화면, 반응형 스타일
- `app.js`: 편집기, 탐색, 가져오기, 내보내기
- `note-content.js`: 확장된 예시 노트 및 기존 샘플 보완
- `study-notes.js`: 필기 첨부·반영, 편집 습관 추천
- `settings.js`: 세 가지 DNA, 마이그레이션, 자동 저장, 모드, 미리보기
- `icon.svg`: 아이콘

## 확인

JavaScript 구문과 정적 자산 참조를 확인했습니다. 비브라우저 DOM 환경에서 12개 점검을 통과했습니다. 항목 이동·순서, 단계별 번호와 미리보기, 아코디언 상호 배타 동작, 예시 전체 해제·재선택, 저장 유지, 버전 4·5 마이그레이션과 새 과목 초안 분리를 확인했습니다. 실제 브라우저 시각·인쇄 및 IndexedDB 테스트는 별도로 진행하지 않았습니다.
