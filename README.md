# Note DNA

HTML, CSS, JavaScript로 만든 문서 중심 노트 UI 프로토타입입니다.

- 배포: https://siajin.github.io/gyeol-notes/
- 로컬 실행: `python -m http.server 4174 --directory notion-ui`

## 개인화 설정

모든 선택 항목을 같은 가로 버튼형으로 통일했습니다. 각 설정은 제목·선택지·설명 순서의 독립된 행으로 표시하고, 여백과 구분선으로 구별합니다. 여러 개를 선택하는 예시·문제 유형도 같은 모양을 사용하되 복수 선택 표시를 붙였습니다. 수량 입력은 동일한 숫자 입력 모양을 사용합니다. 번호·강조, 수식·용어, 자료 우선순위 같은 세부 설정은 접을 수 있습니다. 과목별 항목은 구조·내용으로 나누지 않고, 학습 모드가 내용을 일괄 설정합니다. 작은 화면에서는 같은 선택지를 줄바꿈합니다.

### 기본 DNA

과목이 바뀌어도 유지되는 표현 방식입니다. 제목 구조, 번호 표기, 표와 목록 선호도, 강조 방식, 문체를 설정합니다. 자주 쓰는 노트 단계·내용 배치·문체를 먼저 보여주고, 번호와 강조는 세부 설정으로 묶었습니다. 강조는 굵은 글씨·은은한 배경색·색 밑줄·별표와 강조 빈도를 별도로 선택합니다. 문체 선택은 짧은 설명으로 비교하며, 과목별 예문은 미리보기에서만 보여줍니다. 운영체제·알고리즘·선형대수는 서로 다른 예문을 사용하고, 그 밖의 과목에는 특정 전공 지식을 가정하지 않는 중립적인 예시를 제공합니다. 기본 DNA의 예시 과목 변경은 저장된 설정에 영향을 주지 않습니다.

### 과목별 DNA

구조·내용 구분 없이 하나의 목록에서 정리 순서와 내용 관련 항목을 설정합니다.

예시 종류와 개수, 수식·용어 설명 수준, 노트 분량, PDF·교재·개인 필기·교수 설명 반영도, 외부 자료 보강 정도와 시각자료 종류를 설정합니다. 수식이 없는 과목은 수식 항목을 숨길 수 있습니다.

상단의 한 번에 맞추기에서 개념 이해·심화 학습·시험 대비를 누르면 예시·설명·분량·자료 반영을 함께 조절합니다. 개념 이해는 예시와 수식·용어 설명을 늘리고 외부 보강을 끕니다. 심화 학습은 기본 설명을 줄이고 외부 학술자료를 보강합니다. 시험 대비는 교수 강조와 필기를 우선합니다. 적용 후에도 개별 항목을 자유롭게 바꿀 수 있고, 변경하면 맞춤 설정으로 표시합니다. 같은 구성을 다시 눌러 권장값을 적용할 수 있습니다. 정리 순서와 기본 DNA·학습 DNA는 변경하지 않습니다.

### 학습 DNA

선택한 과목의 문제 유형(객관식·단답형·서술형·OX, 복수 선택), 문제 개수, 난이도, 이번 시험 범위, 챕터별·챕터 융합 출제를 설정합니다. 과목별 학습 모드를 바꿔도 학습 DNA는 바뀌지 않습니다. 시험 범위를 비우면 등록 자료 전체를 사용하며, 문제 개수가 0이면 생성하지 않도록 설정합니다.

모든 설정은 자동 저장됩니다. 새 과목을 만드는 화면에서 과목별 DNA와 학습 DNA를 함께 설정할 수 있습니다. 새 노트는 해당 과목의 DNA를 가져옵니다. 이전의 일회성 모드 설정 화면은 이 세 가지 구조로 통합했습니다.

예시는 비유·실생활 사례·단계별 풀이·응용을 복수 선택하고, 개념당 총 0~10개를 지정합니다. 0개는 예시 없이 정리하며 선택한 종류는 유지합니다. 미리보기는 선택한 방식의 대표 표현을 최대 2종 보여줍니다. 실제 노트 생성 결과로 표시하지 않습니다.

## 기존 기능

예시 노트 5개, 핵심 요약, 접는 계산 예제·복습 질문, 직접 편집, 블록 이동, 실행 취소, 검색, 즐겨찾기, 시험 보기, Markdown·HTML·인쇄 내보내기를 지원합니다.

수업 필기는 TXT·Markdown을 읽거나 텍스트를 붙여넣어 정리에 반영합니다. 개인 필기 반영도·중요도·강조 구절 우선 설정을 적용합니다. 특정 자료 선택과 새로 추가한 자료만 반영하는 옵션은 필기 첨부 관리에서 조절합니다. 직접 수정한 필기 정리 블록은 다시 반영할 때 보존합니다.

편집 습관 추천은 같은 과목의 긴 설명을 수정한 노트가 3개 이상이고, 최근 최대 5개의 평균 감소율이 20% 이상일 때 과목별 노트 분량을 줄이도록 제안합니다. 적용·무시가 가능하며 기본 DNA나 학습 DNA는 변경하지 않습니다.

## 저장과 마이그레이션

노트와 설정은 localStorage, 원본 파일은 IndexedDB에 저장합니다. 기존 저장 키를 유지합니다. 버전 4에서는 기본 DNA의 정리 기준·예시 선호도를 과목별 DNA로, 이전 문제 설정과 최근 노트의 시험 범위를 과목별 학습 DNA로 옮깁니다. 기존 과목도 새 모드의 설명·외부 보강 정책으로 한 번 맞춥니다. 이후 직접 바꾼 값은 유지합니다. 이전 설정 스냅샷을 `previousDNA`에 보관하고, 노트 본문·메모·첨부 원본·기존 일회성 데이터는 지우지 않습니다.

- `personalDNA`: 공통 표현 방식
- `subjectDNA`: 과목별 정리 순서와 내용 설정
- `learningDNA`: 과목별 문제·시험 준비 설정

버전 5에서는 이전 예시 설정을 종류 배열(`exampleTypes`)과 개념당 개수(`exampleCount`)로 옮깁니다. 과목별로 별도 저장하며, 기존의 다른 설정이나 노트는 다시 초기화하지 않습니다.

DNA JSON 내보내기는 이 세 범주와 예시 종류·개수를 포함합니다.

## 제공 범위

설정 저장·미리보기·모드 전환·텍스트 필기 반영이 동작하는 프런트엔드 프로토타입입니다. 실제 AI 호출, OCR, 자동 문제·시각자료 생성, 학술자료 검색, 로그인·동기화는 연결되지 않았습니다. 기존 본문을 설정 변경만으로 다시 쓰지 않습니다. PDF·이미지는 원본 보관 후 텍스트를 보완해 반영할 수 있습니다.

## 파일

- `index.html`: 진입점
- `styles.css`, `theme.css`: 기본 레이아웃, 흰 배경, 설정 화면, 반응형 스타일
- `app.js`: 편집기, 탐색, 가져오기, 내보내기
- `note-content.js`: 확장된 예시 노트 및 기존 샘플 보완
- `study-notes.js`: 필기 첨부·반영, 편집 습관 추천
- `settings.js`: 세 가지 DNA, 마이그레이션, 자동 저장, 모드, 미리보기
- `icon.svg`: 아이콘

## 확인

JavaScript 구문과 정적 자산 참조를 확인했습니다. 비브라우저 DOM 환경에서 통일된 설정 UI 점검 9개를 통과했습니다. 모든 설정의 행 구분, 단일·복수 선택, 숫자·참거짓 값 저장, 일괄 설정 동기화, 예시 0개 처리, 저장 복원과 새 과목 초안 분리를 확인했습니다. 실제 브라우저 시각·드래그·인쇄 및 IndexedDB 테스트는 별도로 진행하지 않았습니다.

선택지의 표현을 짧고 행동 중심으로 정리했습니다. 예시의 종류와 개수는 서로 독립적으로 조절합니다. 기존 저장값은 유지하면서 화면 문구만 대응시켜 기존 취향이 바뀌지 않게 했습니다. 수식·용어의 세부 설명과 자료 우선순위도 접어서 표시합니다.
