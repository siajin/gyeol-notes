# 결 — 노트 UI / UX

별도 프레임워크 없이 HTML, CSS, JavaScript로 만든 노트 서비스 프로토타입입니다.
같은 작업 폴더의 다른 UI 결과와 섞이지 않도록 `notion-ui` 폴더에 분리했습니다.

## 열기

`index.html`을 브라우저로 열면 사용할 수 있습니다.
파일 보관 기능까지 사용할 때는 아래처럼 로컬 서버로 여는 것을 권장합니다.

```text
python -m http.server 4174 --directory notion-ui
```

주소: http://localhost:4174

## 화면 구성

- 문서 중심 노트 편집기: 과목 탐색, 목차, 선택 시에만 표시되는 편집 메뉴
- 내 노트: 최근 노트, 제목·내용 검색, 과목 필터, 즐겨찾기
- Note DNA: 과목별 설명량·정리 구조·수식·강조 설정, 즉시 바뀌는 예시
- 템플릿: 기본 스타일 미리보기와 항목별 조합
- 새 노트: 빈 노트 또는 파일 가져오기, 새 과목 추가

## 실제 동작

- 제목·본문 직접 편집, 사용자 메모, 블록 드래그 및 메뉴로 순서 이동
- 블록별 수정 전후 비교, 적용·취소, 복제·삭제·실행 취소
- 중요 표시 기반 시험 모드, 예제 수식 설명
- 과목별 설정 저장, 실제 편집 기록을 통한 설명량 추천 및 적용·무시
- Markdown·텍스트 가져오기 및 규칙 기반 스타일 초안
- PDF·PPT·Word·이미지 파일의 기기 내 보관, PDF·이미지·텍스트 원본 보기
- Markdown, HTML, 인쇄/PDF 내보내기, Note DNA JSON 내보내기
- 모바일 레이아웃, 키보드 접근, 입력 내용 정제

노트와 설정은 localStorage에, 원본 파일은 IndexedDB에 저장합니다.
다른 브라우저·주소에서는 별도 공간으로 취급됩니다. 영구 보관할 노트는 파일로 내보내세요.

## 시연 범위

샘플 노트와 다듬기 문장은 미리 준비된 예시입니다.
실제 AI 모델 호출, PDF/PPT 자동 분석, 웹 검색, 계정 동기화, 온라인 템플릿 마켓은 포함하지 않습니다.
사용자 메모는 자동 다듬기 대상에서 제외됩니다.
기존 노트 스타일 가져오기는 Markdown·텍스트의 문장 길이와 항목 형식을 측정하는 규칙 기반 초안입니다.

## 파일

- `index.html`: 문서 진입점
- `styles.css`: 레이아웃, 서체, 반응형, 인쇄 스타일
- `app.js`: 샘플 데이터, 화면, 상호작용, 로컬 저장
- `study-notes.js`: 수업 필기 첨부·반영 및 편집 습관 추천
- `icon.svg`: 브랜드 아이콘

폰트는 Google Fonts를 사용하며, 인터넷이 없으면 기기 기본 서체로 표시됩니다.

## 검증

JavaScript 구문과 HTML 자산 경로를 확인했고, 비브라우저 환경에서 초기화·검색·입력 정제·수정 비교·실행 취소·메모 보호·과목별 설정 저장·시험 모드·블록 이동·템플릿·텍스트 가져오기 총 12개 동작 점검을 통과했습니다.
실제 브라우저의 시각·드래그·인쇄·파일 보관 테스트는 별도로 진행하지 않았습니다.
선택적 WebMCP 인터페이스는 지원 여부를 감지한 뒤 등록하며, 실제 WebMCP 브라우저 환경 검증은 진행하지 않았습니다.

## 추가된 수업 필기와 습관 추천

노트 상단의 **수업 필기 → 필기 첨부**에서 텍스트 파일, Markdown, PDF, 이미지를 보관하거나 내용을 직접 붙여넣을 수 있습니다. **정리에 반영**에서 Note DNA를 적용한 결과를 확인한 뒤 적용합니다. 필기 원문과 출처를 별도로 보관하며, 직접 편집한 필기 정리 블록은 다시 반영할 때 보존합니다.

Note DNA의 **수업 필기 반영**에서 반영 정도(반영 안 함 / 핵심만 / 균형 있게 / 가능한 모두), 중요도(참고 / 중요 / 최우선), 강조한 구절 우선 반영을 조절합니다. 중요도는 시험 모드에도 반영됩니다.

현재 필기 정리는 입력된 텍스트 구절을 선택하고 형식을 정돈하는 로컬 기능입니다. PDF·사진의 자동 문자 인식(OCR)과 AI 요약은 연결되지 않았으며, 이 형식들은 원본 보관과 텍스트 보완 후 반영을 지원합니다.

**편집 습관에서 발견했어요**는 같은 과목의 실제 편집 기록으로 추천합니다. 긴 설명(처음 80자 이상)을 수정한 노트가 3개 이상이면 최근 최대 5개의 감소율을 노트별로 평균 냅니다. 같은 블록의 반복 편집은 최초 길이와 최종 길이로 비교합니다. 사용자 메모·첨부 필기·형식 변환은 제외하고, 평균 20% 이상 줄였으며 현재 설명량이 ‘핵심만’이 아닐 때 추천합니다.

‘적용’은 해당 과목 설정을 저장하고, ‘무시’는 설정을 유지하면서 동일 근거의 추천을 숨깁니다. 새 편집 근거가 생기면 다시 평가합니다. 기록이 부족한 경우 **추천 예시 보기**로 요청한 ‘노트 5개, 평균 32% 감소’ 카드의 표시 예시를 확인할 수 있으며, 이를 실제 사용 기록으로 저장하지 않습니다.

추가 기능은 비브라우저 환경에서 필기 반영량·출처·보존·중복 방지·파일 검증·추천 집계·과목 격리·적용·무시·저장 유지 등 20개 점검을 통과했습니다.
